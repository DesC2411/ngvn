# May Academy – Mùa Tri Ân 20/11

Web game 3D để học sinh May Academy tri ân thầy cô ngày 20/11/2026: đi lại trong trường, viết thiệp treo lên cây của từng thầy cô, thả hạc, ký bảng đen, gửi "Lời chưa nói", chụp ảnh, đố vui, Xin Vía.

```bash
npm ci
cp .env.example .env   # điền ADMIN_KEY
npm run dev            # http://localhost:8820
```
